HTML Fundamentals

When writing HTML, proper text formatting is crucial for readability. Semantic markup helps convey meaning, not just style. For example, you can highlight important information using the mark tag. When showing code, use the code tag like this: const greeting = "Hello World!";. For preserving whitespace and formatting, use the pre tag: 

    function sayHello() {
        console.log("Hello!");
        console.log("How are you?");
    }
This maintains all spacing and line breaks exactly as written.
